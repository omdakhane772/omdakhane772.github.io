# Om Dakhane - Cloud & DevOps Portfolio

Modern, responsive portfolio website built with **React**, **Vite**, and **Vanilla CSS**.

## Features

- **Interactive Cloud Architecture Lab**: Interactive AWS VPC architecture diagram with Simple and Expanded views, service explanations, and request tracer.
- **Simulated Linux Terminal**: Command-line simulation with runnable Linux commands (`whoami`, `pwd`, `ls`, `echo`, `help`, `clear`).
- **Showcase Projects**: Microservices, backend systems, and AWS integrations with animated SVG packet flows and deep-dive technical modals.
- **Interactive Tech Stack**: Categorized skill pills with expandable use-case cards.
- **Ambient Graphics**: HTML5 Canvas particle network with interactive mouse repulsion and glowing pulses.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

## Deployment

Automated deployments to GitHub Pages run via GitHub Actions on push to `main`.
